## 📖 About The Project

**EPIC (East Point Performance Intelligence Center)** is a comprehensive AI-powered platform designed to analyze and predict student academic performance. Built as part of my academic project, this system helps educators identify at-risk students early and provides personalized feedback to help students improve their performance.

The idea came from observing how traditional academic tracking systems often fail to provide actionable insights. I wanted to create something that not only tracks performance but actually predicts future outcomes and suggests improvements.

### What makes EPIC different?

- **Predictive Analytics**: Instead of just showing past data, EPIC predicts future performance using ML
- **Personalized Feedback**: AI-generated suggestions tailored to each student's metrics
- **Beautiful UI**: Modern, responsive design that's actually pleasant to use
- **Real-time Analysis**: Get instant predictions as soon as you enter data

## 🚀 Getting Started

### Prerequisites

Before you begin, make sure you have:
- **Node.js 18+** and npm installed
- **Python 3.8+** with pip
- A **Firebase** project (for authentication)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Mohammed-razin-cr/epic.git
cd epic
```

**2. Set up the Backend**

```bash
# Navigate to backend folder
cd backend

# Create a virtual environment
python -m venv venv

# Activate it
# On Windows:
.\venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start the Flask server
python app.py
```

The backend will be running at `http://localhost:5000`

**3. Set up the Frontend**

Open a new terminal in the project root:

```bash
# Install Node dependencies
npm install

# Create environment file
cp .env.example .env.local

# Edit .env.local and add your Firebase config
# Then start the development server
npm run dev
```

The frontend will be running at `http://localhost:3000`

**4. Configure Firebase**

Create a `.env.local` file with your Firebase configuration:

```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
NEXT_PUBLIC_API_URL=http://localhost:5000
```

## 📡 API Reference

### Health Check
```http
GET /api/health
```
Returns API status and model loading state.

### Predict Performance
```http
POST /api/predict
Content-Type: application/json

{
  "cgpa": 8.5,
  "credits": 120,
  "extraCurricular": 3,
  "projects": 4,
  "selfStudy": 5,
  "assignment": 0.9,
  "engagement": 8,
  "contribution": 7
}
```

**Response:**
```json
{
  "success": true,
  "prediction": {
    "grade": "A",
    "passProbability": 85,
    "risk": "Low",
    "improvementPotential": 8.5
  }
}
```

### Predict with Feedback
```http
POST /api/predict-with-feedback
```
Same as above, but includes personalized AI feedback in the response.

## 🤖 How the ML Model Works

The prediction system uses a **Support Vector Machine (SVM)** model trained on student performance data. Here's what it considers:

| Feature | Description | Range |
|---------|-------------|-------|
| CGPA | Cumulative Grade Point Average | 0-10 |
| Credits | Total credits completed | 0-200 |
| Extracurricular | Number of activities | 0-10 |
| Projects | Completed projects count | 0-10 |
| Self Study | Daily study hours | 0-10 |
| Assignment | Completion rate | 0-1 |
| Engagement | Subject interest level | 0-10 |
| Contribution | Faculty support needed | 0-10 |

The model outputs an improvement potential score (0-10) which is used to determine:
- **Predicted Grade**: A+, A, B+, B, C+, C, D, or F
- **Pass Probability**: Percentage chance of passing
- **Risk Level**: Low, Medium, or High

## 🔧 Troubleshooting

**Backend won't connect?**
- Make sure Flask is running on port 5000
- Check that CORS is enabled
- Verify `NEXT_PUBLIC_API_URL` in your `.env.local`

**Model loading errors?**
- Ensure `trainmlx.pkl` exists in the backend folder
- Check Python version (need 3.8+)
- Try reinstalling: `pip install scikit-learn`

**Frontend issues?**
- Clear Next.js cache: `rm -rf .next`
- Reinstall deps: `rm -rf node_modules && npm install`
